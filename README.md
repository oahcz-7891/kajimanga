# Kajimanga

Kajimanga 是一个浏览器端漫画翻译阅读器：导入漫画、离线书架、流畅阅读；框选页面区域即可调用视觉大模型完成日文识别与翻译。纯前端实现，本地运行，无服务端依赖。

## 功能

- 支持导入 ZIP / CBZ / RAR / CBR / PDF 格式漫画
- IndexedDB 离线书架，保存漫画与阅读进度，随时继续阅读
- 阅读器支持左右热区翻页、推页式翻页动画、双击缩放、拖动平移
- 框选任意区域，OCR 识别日文并翻译为简体中文
- 学习模式：额外返回语法说明与单词 / 短语释义
- 移动端适配，iOS 风格页面切换

## 使用说明

### 导入漫画

支持把压缩包 / PDF 直接拖入窗口，或点击「导入漫画」选择文件。图片页面会自动生成封面缩略图并存入书架；导入失败会有错误提示。

### 书架

- 漫画以 IndexedDB 形式缓存在本地，刷新页面后依然存在
- 每本漫画记录阅读进度，点击封面可继续阅读
- 封面右上角 × 可移除漫画

### 阅读器

| 操作 | 效果 |
|------|------|
| 点击页面左 / 右边缘热区 | 上一页 / 下一页 |
| 点击顶栏 / 底部导航按钮 | 翻页 |
| 双击页面中央 | 放大 / 还原（倍率可在设置调整） |
| 放大后拖动 | 平移 |
| 点击「翻译」 | 进入框选模式，拖动划出翻译区域 |

翻页动画为推页式滑动；缩放状态只对当前页有效，翻页后自动恢复。

### 翻译

1. 点击顶栏「翻译」进入框选模式
2. 在页面上拖出要翻译的文字区域（支持缩放状态下框选）
3. 松手后自动裁剪该区域并调用视觉模型
4. 识别结果以译文卡片形式显示在选区旁

支持的服务商（OpenAI 兼容接口）：DeepSeek、Qwen（DashScope）、Kimi（Moonshot）、自定义。每个服务商可独立配置 `baseUrl / API Key / 模型名 / 思考档位`，支持「测试连接」。

翻译模式分为「翻译」与「学习」两种：翻译返回日文原文与中文译文；学习额外返回语法说明与单词 / 短语释义。

### 设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 双击缩放 | 开启 | 双击页面切换放大 / 还原 |
| 缩放倍率 | 2x | 双击放大的倍率 |
| 翻译模式 | 翻译 | 翻译模式 / 学习模式 |

设置保存在浏览器本地存储中。

## 技术栈

- React 18 + TypeScript
- Vite 5
- JSZip / node-unrar-js（WASM 解压）
- pdfjs-dist（PDF 渲染）
- IndexedDB（书架与进度存储）

## 隐私说明

- 所有数据保存在本地浏览器：漫画文件、书架、阅读进度均不出本机
- 只有框选出的那一小块图片会发送到你配置的服务商 API 用于识别和翻译，页面整体不会上传
- API Key 仅存储在浏览器 localStorage
